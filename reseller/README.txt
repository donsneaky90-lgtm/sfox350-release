FOLDER RESELLER SFOX

Edit ResellerSFOX.json untuk mengubah isi dialog reseller.
Simpan gambar logo reseller di folder ini, lalu isi alamat gambar tersebut
pada bagian logoUrl di ResellerSFOX.json.

Contoh alamat logo:
https://raw.githubusercontent.com/donsneaky90-lgtm/sfox350-release/main/reseller/nama_logo.jpeg

Setelah mengubah JSON atau gambar, commit dan push folder reseller ke GitHub.
Aplikasi mengambil data terbaru saat dialog reseller dibuka.
